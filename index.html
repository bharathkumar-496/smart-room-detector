Deploy Your Smart Room Proctor Website

Because this application runs entirely client-side using TensorFlow.js, you can host it for free with zero backend server maintenance. Choose any of these 3 instant methods:

▲ Option 1: Deploy with Vercel (Instant 30s) Recommended
  1. In this project directory, run: npx vercel
  2. Follow the quick prompts (Log in with GitHub / Email).
  3. You receive an instant live URL like https://smart-room-proctor.vercel.app with HTTPS and camera permissions enabled!
Option 2: Netlify Drop (Zero Terminal / Drag & Drop)
  1. Open app.netlify.com/drop in your browser.
  2. Drag & drop the entire smart-room-detector folder onto Netlify.
  3. Netlify instantly deploys it and gives you a public HTTPS website.
Option 3: GitHub Pages (Permanent Free Hosting)
  1. Create a new repository on GitHub (e.g. smart-room-proctor).
  2. Push these files to the main branch.
  3. Go to Repository Settings → Pages, select Branch: main, and click Save.
